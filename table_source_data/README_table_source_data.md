# Table source data

This folder contains public aggregate source files for the manuscript main table and public supplementary tables in the current Heliyon submission numbering.

Included here:

- Table 1: model performance leaderboard.
- Supplementary Table 1: benchmark suite.
- Supplementary Table 2: instance distribution.
- Supplementary Table 3: model registry and run configuration.
- Supplementary Table 4: open-task scoring dimensions.
- Supplementary Table 6: LLM-jury combination robustness.
- Supplementary Table 7: cost-performance data.

Not included in this public code repository:

- Supplementary Table 5: full model responses and LLM-jury scores.
- Supplementary Table 8: senior neurologist ratings.
- Supplementary Table 9: senior-neurologist validation summary.

These files are handled as manuscript/supplementary submission materials or are available according to the manuscript data availability statement.
